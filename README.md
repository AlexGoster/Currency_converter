# Currency Converter

Конвертер валют с GUI на Python.

## Возможности

- Выбор валюты из списка и ввод суммы
- Курсы хранятся в файле `rates.json` (базовая валюта — USD)
- Интерфейс на Tkinter

## Запуск

```bash
python main.py
```

## Формат курсов

```json
{
    "USD": 1.0,
    "EUR": 0.85,
    "RUB": 75.0,
    "GBP": 0.73
}
```
